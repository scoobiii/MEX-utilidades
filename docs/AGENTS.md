# Guia para agentes

Fluxo: INSPECT → PLAN → TEST → AUDIT → VERIFY → PUBLISH.

JR segue contratos existentes. SENIOR pode propor arquitetura e adapters com testes. REVIEWER procura violações de proveniência, segurança e cobertura. DEVOPS valida CI, observabilidade e rollback.

Nunca inventar telemetria, suporte de fabricante, diagnóstico ou sucesso de integração. Nunca converter INFERRED em OBSERVED.
