# Guia do gestor / PMOC

Acompanhar ativos, status, planos, distribuição, aderência, consumo, disponibilidade, evidências e auditoria.

Status: OK verde; preventiva laranja; corretiva vermelho; projeto azul; descomissionamento roxo; estoque para retirada/reutilização; sucata preto.

As cores são apoio visual; texto e semântica acessível permanecem obrigatórios.

Um plano só sincroniza quando há plano ativo e alinhamento com PMOC.
